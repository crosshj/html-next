## Overview The `Button` component provides interactive elements with multiple variants, sizes, and states. It supports icons, navigation, and comprehensive styling options for a complete button system. ## Features - **Multiple Variants**: Primary, secondary, outlined, and text buttons - **Size Options**: Small, medium, and large sizes - **Icon Support**: Can include Font Awesome icons with left/right positioning - **State Management**: Disabled and loading states - **Navigation**: Can act as a link with the `href` attribute - **Custom Styling**: Full support for the `sx:` attribute system - **Theme Integration**: Consistent with the design system ## Attributes | Attribute | Type | Required | Default | Description | |-----------|------|----------|---------|-------------| | `variant` | string | No | `primary` | Button style: `primary`, `secondary`, `outlined`, `text` | | `size` | string | No | `medium` | Button size: `small`, `medium`, `large` | | `label` | string | No | - | Button text content | | `icon` | string | No | - | Font Awesome icon name in PascalCase | | `iconPosition` | string | No | `left` | Icon position: `left`, `right` | | `href` | string | No | - | URL or path for navigation (makes button act as link) | | `disabled` | boolean | No | `false` | Whether the button is disabled | | `loading` | boolean | No | `false` | Whether the button shows loading state | ## Usage ```html ``` ## Examples ### Button Variants ### Button Sizes ### Buttons with Icons ### Icon Positioning ### Button States ### Navigation Buttons ## Using Buttons as Links The `href` attribute allows buttons to function as navigation links: ### Basic Link Button ```html ``` ### Link Button with Icon ```html ``` ### External Links ```html ``` ### Styled Link Buttons ```html ``` **Note**: When using `href`, the button automatically handles navigation and state management, making it perfect for navigation menus, call-to-action buttons, and interactive links.
