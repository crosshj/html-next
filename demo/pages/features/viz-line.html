The `VizLine` component provides a simple line chart visualization for displaying data arrays. It automatically scales points based on the maximum value and renders each data point as a connected line with labels and values, perfect for showing trends over time. ## Attributes | Attribute | Type | Required | Description | |-----------|------|----------|-------------| | `data` | string | Yes | State path to the data array | | `color` | string | No | Base color for the line chart (hex, rgb, or CSS custom property) | | `variant` | string | No | Chart variant: default (straight lines) or "smooth" (curved lines) | | `fill` | boolean | No | Add translucent area fill under the line (true or empty attribute) | ## Data Format The component expects an array of objects with `label` and `value` properties: ```javascript [ { label: "Mon", value: 1200 }, { label: "Tue", value: 1900 }, { label: "Wed", value: 3000 }, { label: "Thu", value: 5000 } ] ``` ## Default Usage ```html ``` ## Custom Color ```html ``` ## Smooth Variant (Curved Lines) ```html ``` ## With Area Fill ```html ```
