`x-navbar` renders a clickable breadcrumb navigation and an optional hamburger, and places any children as right-side actions. ## Attributes | Attribute | Type | Required | Default | Description | |--------------------|---------|----------|--------------|---------------------------------------------------------------------| | `menuButtonShow` | boolean | No | - | When "true", shows a hamburger button on the left. | | `menuButtonTarget` | string | No | "sidebar" | Clicking hamburger toggles "open" class on element with "id". | | `titleSource` | string | No | "activePath" | Global state key used to build the breadcrumb title. | | `titleText` | string | No | - | When provided, bypasses automatic breadcrumb generation. | > **Breadcrumbs**: Uses global `activePath` (configurable via `titleSource`) to generate clickable breadcrumb navigation. Set `titleSource` to any global state key (e.g., `manualPath`) to control the breadcrumb path. Each segment is a clickable link that navigates to that path. > **Actions**: Any child content of `x-navbar` is placed at the far right. ## Examples ### Basic ```html ``` ### No hamburger ```html ``` ### With actions ```html Help Settings ``` Help Settings ### Manual path ```html ``` ### Manual title ```html ``` ### Title Source ```html ``` > This is useful for cases where default path contains items you don't want visible in breadcrumbs; like with query parameters.
