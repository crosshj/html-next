The `VizPie` component provides a simple pie chart visualization for displaying data arrays. It automatically calculates angles and renders each data point as a colored slice with a legend showing labels and values. ## Features - **Automatic Scaling**: Slices are automatically sized based on data values - **Data Subscription**: Automatically updates when data changes - **Legend Display**: Shows labels and values for each slice - **Color Assignment**: Automatically assigns colors to slices - **Error Handling**: Graceful handling of missing or invalid data ## Attributes | Attribute | Type | Required | Description | |-----------|------|----------|-------------| | `data` | string | Yes | State path to the data array | | `color` | string | No | Base color for the pie chart (hex, rgb, or CSS custom property) | | `variant` | string | No | Chart variant: default (full pie) or "donut" (donut with hollow center) | ## Data Format The component expects an array of objects with `label` and `value` properties: ```javascript [ { "label": "Desktop", "value": 45 }, { "label": "Mobile", "value": 35 }, { "label": "Tablet", "value": 20 }, { "label": "Game Console", "value": 25 } ] ``` ## Default Usage ```html ``` ## Custom Color ```html ``` ## Donut Variant ```html ```
