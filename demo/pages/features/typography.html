The `Typography` component provides text rendering with predefined variants and full `sx:` styling support. ## Attributes | Attribute | Type | Required | Default | Description | |-----------|------|----------|---------|-------------| | `variant` | string | No | `body1` | Typography variant (h1-h6, body1-body2, subtitle1-subtitle2, caption, overline, strong, em, blockquote) | ## Basic Usage ```html Main Heading Body text Small text ``` ## Styled Typography ```html Colored Heading Styled body text ``` ## Live Examples Heading 1 Heading 2 Heading 3 Heading 4 Heading 5 Heading 6 Body 1 - Main body text for paragraphs and general content. Body 2 - Secondary body text for less prominent content. Subtitle 1 - Section subtitles and medium emphasis text. Subtitle 2 - Smaller subtitles and labels. Caption - Small text for captions and metadata. Overline - Uppercase text for labels and categories. Strong - Bold text for emphasis. Em - Italic text for emphasis. Blockquote - Quoted text with special styling.
