The `Data` component registers data sources with the global state system for access throughout the application. ## Attributes | Attribute | Type | Required | Description | |-----------|------|----------|-------------| | `name` | string | Yes | Unique identifier for the data source | | `defaultValue` | string | No | JSON string containing the initial data | | `route` | string | No | Route pattern for dynamic data loading | ## Basic Usage ```html ``` ## Data Access ```html {{global_userProfile.name}} Admin Panel const currentProfile = global.userProfile; SetData('userProfile', { ...currentProfile, lastLogin: new Date() }); ``` ## Route-based Data ```html const currentPath = `/${global.pathData?.rest || ''}`; SetData('activePath', currentPath); ```
