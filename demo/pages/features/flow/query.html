The `Query` utility function provides HTTP request capabilities for loading external content and making API calls within flows. It's designed for simple GET requests and returns the response content as text. ## Usage ```html const content = await Query({ url: '/api/data' }); SetData('apiResponse', content); ``` ## Parameters | Parameter | Type | Required | Description | |-----------|------|----------|-------------| | `url` | string | Yes | The URL to fetch content from | ## Return Value Returns a Promise that resolves to: - **Success**: The response content as a string - **Error**: An HTML error message wrapped in a div with red styling ## Examples ### Loading API Data ```html const userData = await Query({ url: '/api/users/123' }); const parsed = JSON.parse(userData); SetData('currentUser', parsed); ``` ### Loading External Content ```html const content = await Query({ url: '/fragments/sidebar' }); SetData('sidebarContent', content); ``` ## Error Handling The Query function automatically handles errors and returns a user-friendly error message: ```html const result = await Query({ url: '/nonexistent' }); // result will be: "
Error loading content: ...
" ```
