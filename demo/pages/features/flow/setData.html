The `SetData` utility function provides state management capabilities for updating global application state within flows. It triggers reactive updates across all subscribed components. ## Usage ```html ``` ## Parameters | Parameter | Type | Required | Description | |-----------|------|----------|-------------| | `name` | string | Yes | The state property name to update (supports dot notation for nested properties) | | `value` | any | Yes | The value to set for the property | ## Examples ### Simple State Update ```html ``` ### Complex Object Update ```html ``` ### Array Updates ```html ``` ### Conditional Updates ```html ``` ### Nested Properties (Dot Notation) ```html ``` ## State Access State can be accessed in flows using: - `global.propertyName` - Read-only access to state - `state.propertyName` - Same as global (alias) ## Reactive Updates When `SetData` is called: - All components subscribed to that property will re-render - State changes are logged to console for debugging - The global `window.state` object is updated
