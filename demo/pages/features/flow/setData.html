The `SetData` utility function provides state management capabilities for updating global application state within flows. It triggers reactive updates across all subscribed components. ## Usage ```html SetData('userName', 'John Doe'); ``` ## Parameters | Parameter | Type | Required | Description | |-----------|------|----------|-------------| | `name` | string | Yes | The state property name to update (supports dot notation for nested properties) | | `value` | any | Yes | The value to set for the property | ## Examples ### Simple State Update ```html const current = global_counter || 0; SetData('counter', current + 1); ``` ### Complex Object Update ```html SetData('user', { name: 'Jane Smith', email: 'jane@example.com', role: 'admin' }); ``` ### Array Updates ```html const items = global_items || []; SetData('items', [...items, { id: Date.now(), name: 'New Item' }]); ``` ### Conditional Updates ```html const isEnabled = global_featureEnabled || false; SetData('featureEnabled', !isEnabled); ``` ### Nested Properties (Dot Notation) ```html SetData('forms.login', { username: '', password: '' }); SetData('user.profile.name', 'John Doe'); SetData('settings.theme.color', 'dark'); ``` ## State Access State can be accessed in flows using: - `global.propertyName` - Read-only access to state - `state.propertyName` - Same as global (alias) ## Reactive Updates When `SetData` is called: - All components subscribed to that property will re-render - State changes are logged to console for debugging - The global `window.state` object is updated
