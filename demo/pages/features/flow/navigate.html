The `Navigate` utility function provides programmatic navigation capabilities for changing application routes within flows. It updates the browser's URL hash to trigger route changes. ## Usage ```html Navigate('/dashboard'); ``` ## Parameters | Parameter | Type | Required | Description | |-----------|------|----------|-------------| | `path` | string | Yes | The route path to navigate to | ## Examples ### Basic Navigation ```html Navigate('/'); ``` ### Conditional Navigation ```html if (global_userRole === 'admin') { Navigate('/admin'); } else { Navigate('/dashboard'); } ``` ### Navigation with State ```html SetData('selectedItem', 'item123'); Navigate('/details'); ``` ## Notes - Navigation updates the browser's URL hash (`window.location.hash`) - Route changes trigger the framework's routing system - The path should match your application's route structure - No return value - this is a fire-and-forget operation
