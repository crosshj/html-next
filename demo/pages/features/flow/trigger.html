The `Trigger()` function allows flows to programmatically trigger other flows, enabling complex workflow orchestration and flow composition. ## Signature ```javascript Trigger(flowKey, data) ``` | Parameter | Type | Required | Description | |-----------|------|----------|-------------| | `flowKey` | string | Yes | The key of the flow to trigger | | `data` | object | No | Data to pass to the triggered flow | ## Accessing Trigger Data Triggered flows receive data through the `event` object: | Property | Type | Description | |----------|------|-------------| | `event.data` | object | Data passed via `Trigger(flowKey, data)` | | `event.triggeredBy` | string | Always `'flow'` for flow-triggered flows | | `event.flowStack` | array | Complete call chain: `['flowA', 'flowB', 'flowC']` | ## Usage Trigger another flow from within a flow: ```html await Alert({ message: 'Parent flow: Starting process', title: 'Flow Started', dispose: false, }); Trigger('childFlow', { userId: 123, action: 'update' }); await Alert({ message: 'Child flow: Received data - userId: ' + event.data.userId + ', action: ' + event.data.action + '\nCall chain: ' + event.flowStack.join(' -> '), title: 'Data Received', dispose: false, }); Trigger('grandchildFlow', { processed: true, originalData: event.data }); await Alert({ message: 'Grandchild flow: Processing complete\nCall chain: ' + event.flowStack.join(' -> '), title: 'Processing Complete', }); ``` ## Flow Call Chain The `flowStack` tracks the complete call chain, useful for debugging: ```html await Alert({ message: 'Multi-trigger flow: Starting multiple operations', title: 'Multi-Trigger Started', dispose: false, }); // Trigger multiple flows sequentially await Trigger('validateUser', state.user); await Trigger('validateOrder', state.order); await Trigger('processPayment', state.payment); await Alert({ message: 'All flows triggered successfully', title: 'Multi-Trigger Complete', }); ```
