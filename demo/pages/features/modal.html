The `Modal` component provides a way to create dialogs. This component is primarly used internally, but it is possible to use it currently with a little bit more work than is ideal (see below for an illustration of this). | Parameter | Type | Required | Default | Description | |-----------|------|----------|---------|-------------| | `type` | string | No | - | The type of modal (e.g., 'confirm' for modals with confirm/cancel buttons) | | `title` | string | No | - | The title displayed in the modal header | | `message` | string or html | No | - | The message displayed in the modal body | >Note: for simple use cases you will want to use `Alert` and `Confirm` Flow [modal helper functions](/features/Flow/Modal) for modals instead of creating your own modals directly.
